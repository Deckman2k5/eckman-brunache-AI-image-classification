# Download Instructions
Python Version 3.13 Recommended

To download the requirements, run

```pip install -r req.txt```  

To download the dataset, run  
```py downloadDataset.py```

To clean the dataset, cut and paste your train and test files to a folder called images
, run
```py cleanModelScript.py```

To train and test, run  
```py trainAndTest.py```

To output results , run  
```py viz.py```
